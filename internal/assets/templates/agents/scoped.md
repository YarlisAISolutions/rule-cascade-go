These files are Rule Cascade business rules (`{{rules}}/**/*.ruleset.yaml`) or their configuration
(`rcas.yaml`). Follow "Business rules: Rule Cascade" in `AGENTS.md` and the `rules-cascade` skill:

- Never edit a ruleset directly when acting as an agent: draft it, run `rcas check` until it reports
  `0 failed`, then submit it with the MCP tool `propose_ruleset` (or `rcas derive --propose`). A person
  accepts it with `rcas proposals accept <id>`.
- One concern per rule, a `when` guard for optional fields, `params` for limits, golden tests for
  every rule (pass, fail, boundary, client channel), stable ids and never-reused finding codes.
- Nothing secret in a rule with `enforcement: client` or `both`; the server decides.
- `{{out}}/` is generated by `rcas compile --all`: never edit it.
